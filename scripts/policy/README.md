# Policy Scripts

This directory contains scripts dedicated to normalizing, enriching, validating, and extracting policy data.

## Scripts

- **`enrich_policies_with_master_data.py`**: Enriches base policy data using master policy records.
- **`export_policies_to_json.py`**: Exports policy records into JSON format.
- **`normalize_policy_data.py`**: Normalizes overall policy data (carriers, products, etc.).
- **`normalize_policy_products.py`**: Standardizes product names across policy records.
- **`enrich_policy_commissions.py`**: Enriches policy files with commission calculations.
- **`validate_and_fix_carriers.py`**: Validates and corrects carrier names within policy datasets.
- **`remove_matched_policies.py`**: Removes policies that have already been matched or processed.
- **`compare_policies.py`**: Compares different policy datasets to find discrepancies.
