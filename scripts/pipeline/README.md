# Pipeline Scripts

This directory contains orchestration scripts that run multi-step data processing pipelines.

## Scripts

- **`run_full_policy_pipeline.py`**: Executes the unified policy processing pipeline (enrichment, commission splits, validation, and carrier splitting).
- **`import_policy_list_with_validation.py`**: Matches base policy list records with master policy records and orchestrates the data enrichment, validation, and splitting process.
