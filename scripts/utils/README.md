# Utility Scripts

This directory contains generic, reusable file manipulation utilities (for CSV/Excel).

## Scripts

- **`filter_unique_rows_by_column.py`**: Extracts unique rows from a dataset based on specified columns.
- **`normalize_effective_dates.py`**: Processes and normalizes "Effective Date" formats across records.
- **`find_duplicates.py`**: Identifies duplicate rows within a file.
- **`merge_files.py`**: Joins or concatenates multiple Excel/CSV files.
- **`split_file.py`**: Splits a single file into multiple files based on the values in a particular column.
- **`update_columns.py`**: Utility to update or map specific columns within a dataset.
